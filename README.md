# 🎓 Churn de Plataforma EdTech

> Previsão de churn para edtechs e cursos online. Identifica alunos prestes a cancelar a assinatura e dispara ações de reengajamento personalizadas que aumentam a retenção.

**🌐 Demo ao vivo (web app interativo):** https://jhondados.github.io/edu-churn-edtech/

## 📊 Resultados-chave (KPIs)
**0.92** AUC · **+29%** Retenção · **+24%** LTV · **auto** Reengaj.

## 🧠 Tecnologias de IA
Machine Learning · Churn · Engagement Analytics

## ✨ O que faz
- Score de churn por aluno
- Sinais de desengajamento
- Reengajamento automático
- Otimização de LTV
- Campanhas de retenção

## 🗄️ Fonte de dados real
[Plataforma EdTech + engajamento](https://www.gov.br/mec)

## ⚙️ Como funciona
1. **Coleta de dados reais** — integração com Plataforma EdTech + engajamento
2. **Processamento com IA** — Machine Learning · Churn · Engagement Analytics
3. **Dashboard & insights** — KPIs, gráficos e recomendações acionáveis
4. **Ação automatizada** — alertas, predições e decisões em tempo real
